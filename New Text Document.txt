HTTP Requests

GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, CONNECT, TRACE

GET: Fetches data.
POST: Creates data.
PUT: Replaces data entirely.
PATCH: Modifies data partially.
DELETE: Removes data.
HEAD: Gets headers only (no body).
OPTIONS: Checks allowed methods.
CONNECT: Starts a proxy tunnel.
TRACE: Echoes request for debugging.
